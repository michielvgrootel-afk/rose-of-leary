    Connection to GitHub

    This page saves the timer by updating data.json in your GitHub repository. It needs an access token for that. Create one like this:

    1. Open GitHub → new fine-grained token.
    2. Name it Rose of Leary admin and pick an expiration.
    3. Under Repository access, choose Only select repositories and pick this repository.
    4. Under Permissions → Repository permissions, set Contents to Read and write.
    5. Click Generate token, copy it and paste it below.

    The token is stored only in this browser. Visitors can open this page, but without your token they can't change anything.
